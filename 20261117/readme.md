# 六分量恒包络复用

按照《恒包络复用.pdf》第 13 页完成两项基本实验：多数表决和 POCET。两者均分析单位功率合路信号中六个分量的幅度、相位和复用效率，并比较理论与仿真。本程序采用课件允许的随机序列，不增加噪声、捕获、误码率或优化器实验。

## 文件内容

| 文件 | 内容 |
| --- | --- |
| main.m | 新增验收脚本。两个独立分节分别实现多数表决和 POCET；核心计算均在此文件。 |
| POCET1.m | 老师提供的 64 行输入电平组合与相位查找表，是 main 第二节的依赖。 |
| MajorVote.m | 老师提供的六路 C/A 码多数表决演示，保留原样。 |
| generateCAcode.m | 老师提供的 C/A 码生成函数，供 MajorVote 使用，保留原样。 |

## 操作步骤

1. 将 MATLAB 当前文件夹切换到 `20261117`，打开 `main.m`。本程序使用 MATLAB 基础功能，不需要额外工具箱。
2. 选中第一节，按 Ctrl+Enter，展示图 1 和命令窗口的多数表决结果，同时生成 `result_majority.txt`。
3. 选中第二节，按 Ctrl+Enter，展示图 2 和 POCET 结果，同时生成 `result_pocet.txt`。第二节会自动执行同目录的 `POCET1.m`，不需要提前运行老师脚本。
4. 两节也可以从空工作区分别运行，或点击“运行”一次完成。重复运行会更新图 1、图 2。验收时说明幅度、相位和效率的理论值，以及仿真为何接近理论。

两节都生成六路独立等概率二进制序列，长度为 1,000,000，随机种子为 20261117。映射为 `0 → +1，1 → -1`。多数表决前三路在 I 支路，后三路在 Q 支路；POCET 严格按老师查找表决定各分量的幅度和相位，不额外指定三路 I、三路 Q 的关系。

数值结果同时显示在命令窗口，并以 UTF-8 编码写入 `main.m` 同目录下的两个 TXT 文件。文件不存在时自动创建；重复运行某一节只覆盖该节对应的 TXT，不影响另一节的结果。如需保留历史数据，请先另存旧文件。程序不创建 results 文件夹，也不自动保存图片或生成实验报告；需要图片时手动保存两个图窗即可。命令窗口会显示结果文件的完整路径。

## 已有代码讲解

**generateCAcode.m**：用两个十级移位寄存器产生 G1、G2 序列，根据 PRN 选择 G2 的循环移位，组合成长度为 1023、取值为 ±1 的 C/A 码。

**MajorVote.m**：生成 PRN 1～6 的 C/A 码，前三路相加取 sign 得到 SI，后三路得到 SQ，再构造 `S=(SI+1i*SQ)/sqrt(2)`。它展示前三路及 I 支路合路的前十个码片和星座图；计算 `mean(S.*CAcode)` 得到每路的复相关输出，绝对值为幅度、辐角为相位，六路幅度平方之和为效率。由于有限长度 C/A 码不完全正交，其相关估计与理想独立等概率输入的理论值可能有偏差。

**POCET1.m**：将十进制 0～63 转成六位二进制，第一列为最高位；用 `(-1).^NumBin` 转为 ±1 电平，得到 ListCode；ListPhi 给出对应的 64 个相位，单位为度。它提供已经给定的相位表，本身没有执行优化求解，也没有生成长序列或完成相关仿真。

**main.m 的补充**：第一节增加多数表决的理论对照；第二节读取老师的查找表，先对全部 64 种组合等权求和得到理论值，再用随机序列查表生成信号并仿真。查表索引为 `32*b1+16*b2+8*b3+4*b4+2*b5+b6+1`，加 1 是因为 MATLAB 索引从 1 开始。原脚本打印的查找表文本被捕获，变量 ListCode、ListPhi 仍留在工作区，命令窗口仅显示本实验的对比结果。

## 预期输出形式

每项实验一张图，均有四个子图：星座、前 100 个码片的包络、六路幅度对比和六路相位对比。横轴“分量编号”代表六路输入；幅度和相位图中的“理论”“仿真”代表两种计算结果。

### 实验一：多数表决

- **星座图**：四个点位于 `(±1/√2, ±1/√2)`。I、Q 支路各自只取 ±1，再统一除以 √2，所以只有四种组合；四点到原点的距离都等于 1，说明合路信号恒包络。
- **包络图**：在 1 处的一条水平线。码片变化可以改变相位，但不改变复信号的模；这验证的是离散复基带信号的恒包络性质。
- **幅度图**：六组理论、仿真柱子都接近 0.353553。三路等权多数表决对每路的相关系数是 1/2，再经 I/Q 单位功率归一化除以 √2，因此六路分配相同功率。
- **相位图**：前三路接近 0°，后三路接近 90°。前者进入实部，后者乘以 j 进入虚部，体现 I/Q 正交关系；有限随机样本会带来很小的偏差。

理论效率为 **75%**，仿真接近这个数值。每路功率为 `(1/(2√2))²=1/8`，六路合计为 3/4。剩余 25% 为互调分量的功率，不是噪声，也不是信号总功率丢失。

### 实验二：POCET

- **星座图**：多个不均匀分布的点位于单位圆上，部分点很接近。每种输入组合对应一个给定相位，输出是 `exp(j*相位)`，因此幅度都为 1，但不是等间隔的 64-PSK 星座。
- **包络图**：同样在 1 处形成水平线，说明查表选择不同相位仍保持单位包络。
- **幅度图**：六路高度不同，但每路的理论、仿真柱子应接近，说明给定相位表实现了不等功率分配。
- **相位图**：各路按照表中相位关系分布，不必全部为 0°或 90°。这些是合路信号与各输入相关后得到的分量相位，不是某个星座点的相位。

根据老师当前查找表计算的理论结果约为：

| 分量 | 幅度 | 相位（度） |
| --- | ---: | ---: |
| 1 | 0.463909 | 0.000000 |
| 2 | 0.414933 | 105.238724 |
| 3 | 0.440103 | 76.535136 |
| 4 | 0.328033 | 90.174951 |
| 5 | 0.254093 | 1.636673 |
| 6 | 0.293402 | 0.409996 |

理论效率约为 **83.9325%**，仿真应接近该值。它比本实验多数表决的 75% 高约 8.93 个百分点，表明这张查找表在保持恒包络的同时，把更高比例的总功率分配给六路有用分量。两种方法的功率和相位分配不同，不能据此断言所有约束下的 POCET 都是这个效率。

### 命令窗口和 TXT 中的数值

每节显示六行表格，列名依次为：分量编号、理论幅度、仿真幅度、理论相位（度）、仿真相位（度）；随后打印平均功率、最大包络偏差和理论/仿真效率。平均功率应为 1，包络偏差为零或浮点舍入量级。仿真使用有限随机样本，出现小幅数值偏差是正常的，不能要求每一位小数完全相同。

TXT 保存相同的结果文本，包括实验名称、样本数、随机种子、六路分量对比表、平均功率、最大包络偏差和两种效率。可用记事本或 MATLAB 编辑器直接打开；它们是运行生成的结果文件，不是辅助代码，也不是程序输入。

在 MATLAB R2025a 中已分别从空工作区验证两个分节：当前种子下，多数表决仿真效率为 74.9698%，POCET 为 83.7603%；两者平均功率均为 1，最大包络偏差约为 1.11×10⁻¹⁶。

## 简要原理解释

**恒包络**指复基带合路信号的模不随码片改变。多数表决把每三个 ±1 分量变成一个 ±1 输出，I/Q 组合归一化后模恒为 1；POCET 直接用单位模复指数输出，所以也恒包络。这种性质有利于减轻功放非线性对幅度起伏信号的影响；本实验不额外仿真功放。

**分量幅度和相位**通过相关得到：对第 n 路电平 c_n，计算 `corr_n=mean(c_n.*S)`，幅度是 `abs(corr_n)`，相位是 `angle(corr_n)`。输入独立且等概率时，与该路无关的项在平均中趋近零，因此可以提取这一路在合路信号中的复系数。

**理论与仿真**的区别在于平均方式。POCET 理论计算对全部 64 种等概率组合求精确平均：`corr=ListCode.'*exp(1i*ListPhi*pi/180)/64`；随机仿真以大量样本平均近似这个值。多数表决也基于独立等概率假设得到每路幅度 1/(2√2)。单位总功率时，效率就是六个分量幅度的平方和；仿真程序同时计算实际平均总功率并以它归一化。

验收时可以说：“我分别用多数表决和相位查表复用六路信号。星座点都在单位圆上、包络曲线恒为 1，验证了恒包络；相关输出给出各分量幅度和相位。多数表决等功率分配，理论效率 75%；老师给定的 POCET 表是不等功率分配，理论效率约 83.93%，随机仿真与理论接近。”
