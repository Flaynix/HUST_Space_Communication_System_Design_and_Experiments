# BPSK(1) 多路径效应实验

只完成《多路径效应.pdf》第 12 页的必做内容：BPSK(1) 信号在 2 MHz、24 MHz 前端带宽下的多径误差包络。多径相对时延为 0～1.3 Tc，反射信号与直达信号的功率比为 −6 dB。不实现第 12、13 页选做的 BOC(1,1)。

**先用一句话理解：卫星信号遇到反射后，接收机可能把到达时间判断错，从而把距离算错；本实验比较两种接收带宽下，这个错误有多大。**

本文将实验操作和验收时需要理解的概念整理在一起。误差符号统一采用老师验收后修正的版本：**估计距离减真实距离**。前期讨论中使用的相反符号不再用于当前程序。

### 参数怎么理解：BPSK(1)、Tc、码片长度和功率比

可以把 BPSK 码序列看成一串等时长的 `+1、−1` 小方块，每个小方块称为一个“码片”，调制到载波后对应两个相差 180° 的相位。BPSK(1) 中的“1”表示码片速率是 1.023 MHz 的一倍，即每秒 1,023,000 个码片。码片不一定等于信息比特；在扩频通信中，一个信息比特可对应多个码片。

`Tc` 是一个码片持续的时间：

```text
Tc = 1/Rc = 1/1,023,000 秒 ≈ 0.9775 微秒
一个码片对应的传播距离 = 光速 × Tc ≈ 293.05 米
```

“码片长度”要看单位：时间长度约为 0.9775 微秒，空间传播长度约为 293.05 米。这不表示卫星距接收机只有 293 米。

**图的横轴直接来自实验要求的 0～1.3 Tc：** 将反射的额外时延乘以光速，就得到 0～380.968 米的相对路径差。它表示反射信号比直达信号多走了多少路，不是发射方与接收方的总距离。

功率比和幅度比都由要求中的 −6 dB 决定，但转换公式不同：

```text
反射/直达功率比 = 10^(−6/10) ≈ 0.2512
反射/直达幅度比 = 10^(−6/20) ≈ 0.501187
功率比 = 幅度比的平方
```

所以反射信号功率约为直达信号的四分之一，幅度约为一半。信号相加时乘的是幅度比 0.501187，不能直接用功率比 0.2512。

`BW` 则是接收机前端允许通过的频率范围宽度。2 MHz 对应本程序复基带的 −1～+1 MHz，24 MHz 对应 −12～+12 MHz。它与“每秒多少码片”的码片速率不是同一个参数。

### 图的采样精度是谁设置的？

课件给定范围，没有给定数值计算步长。以下数值是程序设置，要区分三层含义：

| 设置 | 代码 | 含义 |
| --- | --- | --- |
| 多径时延扫描步长 | `delayChip = (0:0.005:1.3).'` | 每增加 0.005 Tc 反射延迟算一次误差，共 261 个点；图上横轴点间隔约 1.465 米。 |
| 内部信号采样 | `samplesPerChip = 1024` | 一个码片分成 1024 个采样间隔，时间间隔 Tc/1024 约为 0.955 纳秒，用于计算相关函数。 |
| 相关峰初步搜索 | `searchChip = -0.6:0.002:0.6` | 在候选到达位置上每隔 0.002 Tc 搜索，先确定峰在哪个小区间。 |
| 相关峰细化 | `spline`、`fminbnd`，`TolX=1e-10` | 对相关函数插值，再在峰附近细化位置，避免只能选取粗网格点。 |

第一个步长决定“反射条件每改变多少重新做一次计算”；后面的设置决定“每次计算内部怎样找峰”。**横轴每隔 1.465 米计算一个点，并不意味着纵轴测距误差只能精确到 1.465 米。** 同样，`TolX` 是数值搜索的停止容差，不代表实际测距精度达到 10⁻¹⁰ Tc；数值精度还受到采样、FFT 频率网格、插值及模型近似的影响。

## 预期输出形式

### 图 1：2 MHz 多径误差包络

- 横轴为多径相对路径差，即 `相对时延 × 光速`，范围约 0～381 m，对应要求的 0～1.3 Tc。
- 纵轴为多径引起的测距误差，单位为米。
- 两条曲线分别代表反射信号相移 0°和 180°，构成课件所述的两个极值分支。零延迟处均从零附近出发，随后向正、负两侧偏移，蓝色 0°曲线形成正向波峰，红色 180°曲线形成负向波谷，再逐渐靠近零。
- 最大误差为几十米量级，形状可参考 PDF 第 12 页左侧第一张图。课件示意图横轴画到约 450 m，本程序严格止于 1.3 Tc，约 381 m，因此不能期待画出相同长度的尾部。

**为什么是这样：** 较窄的前端带宽会使相关峰变圆、变宽。延迟到达的反射信号叠加后，容易将这个宽峰的位置拉偏；同相主要产生相加，反相主要产生相减，两种情况导致不同方向的峰值偏移。

**能得出的结论：** 相同 −6 dB 反射功率下，2 MHz 前端对多径峰值偏移较敏感。误差与反射延迟的关系不是一条单调直线，在中间某些延迟处误差更明显。

### 图 2：24 MHz 多径误差包络

- 横轴、纵轴含义和两条曲线的图例与图 1 相同。
- 两条分支主要在零附近的上下几米范围内变化，主要区域中蓝色 0°为正、红色 180°为负，表现为带有小波纹的平台；到路径差约一个码片距离（约 293 m）附近后明显回落，在较大路径差处只剩小幅起伏。
- 形状可参考 PDF 第 12 页右侧第二张图。峰值误差量级明显小于 2 MHz 情况。

**为什么是这样：** 较大的带宽保留了更多信号的高频成分，相关峰更尖锐，反射信号对峰顶位置的影响较小。理想矩形带限会引入相关函数的振铃，所以曲线可以出现细小波纹，不需要把它们当成随机噪声。

**能得出的结论：** 在本实验的信号、功率比和峰值估计方法下，增大前端带宽能显著降低多径误差。但有限带宽并不能让所有多径误差严格消失。

主要误差区域中，同相反射相当于加上一个延迟相关函数，使峰向较晚位置偏移，0°曲线为正；反相反射相当于减去一个延迟相关函数，使峰向较早位置偏移，180°曲线为负。带限振铃会使尾部的小幅误差变号，因此不应强行令所有 0°数据为正、所有 180°数据为负。

验收重点是两个带宽的误差量级、总体包络形状，以及这两个相位分支的含义。不要把这里的“误差包络”和上一节恒包络复用中的“信号幅度包络”混淆：这里画的是不同反射时延下的误差极值分支。

## 简要原理解释

### 1. 多径就是信号的“回声”

接收机除了收到直接到达的信号，还收到经过建筑物等反射后到达的副本。就像喊话后又听到回声，反射信号走了更长的路，通常更晚、更弱，相位也可能不同。本实验只有一条直达路径和一条反射路径，没有加入随机噪声。

### 2. 接收机用相关峰判断信号什么时候到达

接收机准备一份本地参考信号，可以理解成一张“模板”。将模板放到不同时间位置，与收到的信号比较，匹配程度最高的位置，就是相关峰的位置。接收机用这个位置估计信号到达时间。

这里寻找的是“匹配程度曲线”的峰，不是接收信号波形本身的最高点。没有反射时，模板在直达信号的真实到达位置最匹配；加入反射后，收到的是两路信号混合后的形状，最匹配的位置可能改变，形成相关峰偏移。

### 3. 多径测距误差究竟拿什么相减？

比较的是**合成信号的估计到达时间，与直达信号的真实到达时间**，不是直接比较反射信号和直达信号各自晚到多少：

```text
相关峰位置 → 估计到达时间
时间估计误差 = 估计到达时间 − 直达信号真实到达时间
多径测距误差 = 光速 × 时间估计误差
```

真实时延在仿真中设为零，只是把正确到达时刻当作时间原点，并不是说卫星与接收机相距零米。真实接收机并不直接知道这个正确值；仿真中知道它，才能评估误差。

一个帮助理解的假设例子（不是本程序某个实际计算点）：反射晚到 0.5 Tc，而混合信号的相关峰出现在 0.1 Tc。那么反射多走了约 `0.5×293.05=146.5 米`，但接收机估计距离偏大约 `0.1×293.05=29.3 米`。当前定义下测距误差为 **+29.3 米**。

| 量 | 从哪里来 | 图中位置 |
| --- | --- | --- |
| 反射相对时延、相对路径差 | 人为设置反射信号晚到多久、绕路多远 | 横轴 |
| 多径测距误差 | 合成相关峰偏离真实位置多少，再换算成距离 | 纵轴 |

例如，真实距离 1000 米、估计为 1040 米，当前定义的误差就是 +40 米。这仍是**距离误差，不是位置坐标误差**；卫星导航需要结合多颗卫星的测距结果才能求位置，多径测距误差会进一步影响定位。

### 4. 为什么它能够反映多径效应？

在本实验的理想模型中，没有反射时相关峰位于正确位置，误差为零；加入反射后峰发生偏移，说明反射干扰了到达时间判断。我们固定其他条件，只改变反射延迟、相移和前端带宽，因此测距偏差可以直接衡量这些条件下多径对测距的影响。误差绝对值越大，距离估计受到的影响越严重。

它衡量的是多径对“测距”的影响，不代表多径的所有影响。例如反射也可能改变信号强度；当两路没有相对延迟时，反射可以改变相关峰高度而不移动峰的位置，测距误差为零，却不等于没有反射信号。

### 5. 相移 0°、180°为何让两条曲线不同？

相移是反射载波相对于直达载波的相位差，不是反射角度或来波方向。时延表示“晚到多久”，相移表示“波动节奏相差多少”；在本模型中二者分别设置。这里使用的是 **0°和180°，不是0°和90°**。

| 相移 | 对相关函数的作用 | 主要误差区域中的结果 |
| --- | --- | --- |
| 0°：同相 | 加上一个较弱、延迟的相关函数，原峰右侧得到增强 | 峰通常偏晚，距离估计偏大，蓝线为正。 |
| 180°：反相 | 减去一个较弱、延迟的相关函数，原峰右侧受到削弱 | 峰通常偏早，距离估计偏小，红线为负。 |

反射本身仍然晚到。所谓“峰偏早”，是混合形状让接收机的估计偏早，并不是反射信号先于直达信号到达。

真实相位可以是其他值。按照课件给出的峰值估计模型，选用 0°、180°计算误差极值分支，得到多径误差包络。在图上固定同一个横坐标，看蓝线与红线，就是比较“绕路距离相同、反射强弱相同，仅相移不同”的两种误差。尾部振铃可能使分支变号，不能把以上正负关系强加到每一个点。

### 6. 对照代码理解核心计算

本实验用课件第 10 页的等价表达式：

```text
合成相关函数 Rsum(u) = R(u) + alpha × exp(j×phi) × R(u−d)
```

其中 R 是带限 BPSK(1) 的相关函数，d 是反射相对时延，phi 是反射相移。对每个 d，分别令 phi 为 0°、180°，寻找 `abs(Rsum)^2` 的最大值位置，即得到两个误差分支。因为相关运算是线性的，先叠加波形再相关，与先分别相关再叠加等价。

**代码为什么只生成一个矩形码片？** 对独立、等概率的 ±1 矩形码片序列，理想平均自相关由单个矩形脉冲的自相关决定，无限带宽时为三角形。因此程序用单码片构造这个理想相关函数，再在频域施加带宽限制。这是理想 BPSK 码的等效相关仿真，并不是只发送一个信息比特，也不会混入有限长度伪码的相关旁瓣误差。

代码通过 `IFFT(abs(FFT(pulse)).^2 .* H)` 得到带限相关函数，等价于先用 H 滤波再与本地码片相关；再用插值和峰值细化避免采样网格造成明显的误差台阶。

最后把时延误差乘以光速得到测距误差。这里是信号单程传播的距离换算，不需要像往返雷达测距那样除以 2。1 Tc 对应约 293.05 m，所以即使峰值只偏移一小部分码片，也可能产生几米到几十米的测距误差。

## 结果怎样读、验收怎样讲

以 2 MHz 的结果为例：

- 0°分支：最大绝对误差 47.6588 米，出现在 0.665 Tc。意味着反射多走约 194.88 米时，距离估计偏大约 47.66 米，符号为正。
- 180°分支：最大绝对误差 47.6587 米，出现在 0.335 Tc。意味着反射多走约 98.17 米时，距离估计偏小约 47.66 米，符号为负。

“最大绝对误差”是在这一相位下，把扫描过的所有延迟条件进行比较后得到的最严重程度。它不是所有路径差都会出现的固定误差。两个相位可以在不同的反射延迟处达到各自最大值。

验收时按以下顺序展示：

1. 说明范围：“我只做 BPSK(1) 必做部分，单条反射路径、功率比 −6 dB，多径时延 0～1.3 Tc。”
2. 指图的坐标：“横轴是反射多走的距离，来自时延乘光速；纵轴是接收机估计距离减真实距离。”
3. 指两条曲线：“蓝色为 0°同相，红色为 180°反相。它们改变合成相关峰的方式不同，主要区域中分别对应正、负测距误差。”
4. 对比带宽：“2 MHz 时峰顶较平缓，最大绝对误差约 47.66 米；24 MHz 时峰顶更尖锐，降到约 3.84 米。本模型下增大带宽可以减小多径测距误差。”
5. 打开 result.txt：“两种带宽的结果合并在这里，正负号与图一致。反复运行某节只更新对应部分。”

如果老师追问计算方法，可以回答：“我先得到带限 BPSK 的相关函数，再叠加按幅度比缩放、带有延迟和相位的反射相关函数，寻找合成相关峰的位置。峰位置与真实位置之差乘以光速，就是测距误差。”

如果老师追问采样设置，可以回答：“课件没有指定步长，我用 0.005 Tc 扫描反射时延，共 261 点；内部每码片采样 1024 点，并用插值和局部搜索细化峰位置。”
