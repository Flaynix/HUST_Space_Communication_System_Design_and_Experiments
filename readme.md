## 运行与验收

- **20261027**：运行该目录的`main.m`，共6节，部分节依赖前面生成的变量，建议按顺序运行。
- **20261029**：运行该目录的`main.m`，共8节，均可从空工作区独立运行。生成8个图窗，每个图窗为3行1列全范围曲线，横轴为−100～100 Tc，不含局部放大图。噪声实验保留无噪声基准虚线。
- **20261103波形实验**：依次运行`First_order_loop.slx`、`Second_order_loop.slx`、`Third_order_loop.slx`，分别查看`Scope/Scope1/Scope2`的三种激励响应及`Scope3`的2、1、0.1 Hz带宽对比。每个模型均已包含并行电路，无须每次更换信源。稳定时间需按实验README中的统一判据实测记录。
- **20261103噪声实验**：运行`Loop_Bandwidth_Noise_Suppression.slx`后，立即执行`read_out`，读取四组结果并覆盖生成同目录`result.txt`。默认统计50秒之后的数据，现有结果记录为50～500秒。完整接线、实际Gain块名称和参数表见实验README。

- **20261105**：进入`20261105`，打开`main.m`，四个分节均可独立运行（Ctrl+Enter）。同目录的`generateCAcode.m`是必需依赖。图一使用5 ms相干积分、C/N0=40 dB-Hz、种子20261107，左上角自动显示设定与估计的码相位及多普勒频偏；图二至四保持1 ms。只保留课件要求的四项实验，图例和标题已精简。

- **20261110（资料留存）**：本人因生病未参加当天课程，因此本目录只有老师提供的`码分多址.pdf`、`testCDMA.m`和`generateCAcode.m`，没有本人完成的课堂实验代码或验收结果。上述源代码作为学习资料保留，不表示已完成本次实验。
- **20261112**：进入`20261112`并运行外层`testCRC.m`，由它调用同目录下的`GenCRC.m`。脚本生成576位随机信息，分别计算自编和标准的24位CRC，在命令窗口显示两组校验位及是否一致。可先运行计算部分，再运行唯一的`%%`之后的输出部分；本实验不生成图片或结果文件。`original/testCRC.m`保留老师的原始代码，外层版本因兼容性问题将旧`crc.generator`和`generate`接口改为`comm.CRCGenerator`及对象调用方式，验收应运行外层版本。标准结果验证需要Communications Toolbox，自编`GenCRC.m`只使用MATLAB基础功能。

- **20261117**：进入`20261117`，打开`main.m`，两个分节均可从空工作区独立运行（Ctrl+Enter）。第一节为六分量多数表决，前三路在I支路、后三路在Q支路；第二节为POCET，自动读取老师提供的`POCET1.m`相位查找表。两节均采用六路独立等概率随机序列，每路100万个样本，种子为20261117，并映射为±1电平；当前main不使用C/A码，老师的`MajorVote.m`及`generateCAcode.m`保留作参考。每节生成一张含星座、包络、分量幅度及相位对比的汇总图，同时显示并保存数值结果。验收时说明单位包络、各分量幅相及理论/仿真效率：多数表决理论75%、当前仿真74.9698%；给定POCET表理论83.9325%、当前仿真83.7603%。详细解释见内部README。

20261027、20261029、20261105、20261117使用MATLAB基础功能，已在MATLAB R2025a中运行验证；20261103还需要Simulink。噪声读取脚本已验证，但文件夹中的既有结果记录不能替代验收时需要展示的模型、Scope图和稳定时间测量。

程序不自动生成实验报告。20261105自动将四张图导出为PNG、FIG，并保存CSV概率表和MAT数据到实验目录的`results/`；这是可重新生成的结果目录，不是辅助代码或运行输入。删去该目录后运行全部四节即可重新生成；重复运行覆盖同名文件。图一当前结果为设定100 Tc、1000 Hz，估计99.98802 Tc、1000 Hz，其他参数及每张图的现象、结论和原因见内部README。其他实验图形可通过图窗手动保存；`result.txt`为噪声数值统计文件，重复运行`read_out`会覆盖，需保留历史结果时先另存。原始`out`数据如需保存，应另存为MAT文件。

20261117的两节分别将结果以UTF-8文本保存到`main.m`同目录的`result_majority.txt`和`result_pocet.txt`，内容包括样本数、随机种子、六路分量的理论/仿真幅度与相位、平均功率、最大包络偏差和复用效率。它们是可重新生成的结果文件，不是程序输入；重复运行某一节只覆盖该节对应的TXT。程序不自动保存这两张图，需留存时手动保存图窗。
