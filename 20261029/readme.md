## 与课件的对应及参数

依据本目录下 `02 延迟锁定环/延迟锁定环.pdf` 第19、22、24页的最终实验条件，并参考该目录 `DLL` 文件夹中的示例。示例代码中的 PRN 1/10、100.1 Tc 传播延迟等仅为示范；本程序统一采用正式要求的 **PRN 20、传播延迟30 ms、接收多普勒1000 Hz、延迟误差−100:0.1:100 Tc**，共2001点。

- C/A码长1023，码速率1.023 Mchip/s，Tc≈0.9775 μs；积分周期采用课件示例的1 ms。
- 实验一、二采样率100 MHz，对应 `testACF.m`、`testDiscOfDLL.m`；实验三采用 `testDiscOfDLLnoise.m` 的20 MHz。
- 超前/滞后总间隔 `d=1 Tc`，各距即时支路0.5 Tc。
- 实验一初相误差0°、无噪声；实验二多普勒估计正确、无噪声；实验三多普勒估计正确、初相误差0°。
- 单位信号幅度、1 ms内导航数据恒为+1，采用等效复基带模型。传播引入的载波常相位吸收到指定初相误差中。
- 噪声沿用配套示例的**实高斯白噪声**：`randn/sqrt(10^(SNRdB/10))`，在去载波前加入。这里SNR指离散输入信号总功率与噪声方差之比，不是C/N0；也不是I、Q各加一份同方差噪声的模型。
- 随机种子固定为20261029，各噪声节使用同一组标准噪声并按SNR缩放，便于对比且不受运行顺序影响。命令窗口给出该次实际测得的SNR，可能与设定值略有差异。

为避免重复计入同一码周期端点，时间向量采用 `[0,Tp)`，即 `(0:N-1)/fs`，而非课件示例的闭区间 `0:1/fs:Tp`。因此100 MHz下恰好100000点，20 MHz下20000点，与原示例相比少一个端点样本。极小浮点容差仅用于修正整码片边界的舍入误差。

**纵轴已改为课件的累加值。** 相关器用 `sum`，不除以N：实验一正确对齐峰约100000，频偏500 Hz时约63662；除以N后仍为此前版本的1和0.63662。工作区 `normalizedCorrelation` 保留归一化复相关值。包络差、相干差随N缩放，功率差随N²缩放；不同采样率的原始输出不能直接按高度比较。所有噪声图均叠加相同采样率的无噪声基准。

## 预期输出形式

每个图窗均为三行一列，仅显示完整扫描±100 Tc，不包含局部放大图。横轴都是 `(tauHat-tau)/Tc`，0表示延迟估计正确，即估计为30 ms。

### 实验一：相关输出

三行依次是I、Q、幅度。

- **估计1000 Hz：** I在0处出现约100000的尖峰；主峰近似三角形，±1 Tc附近降至接近零。Q约为零。幅度为I的绝对值，远处有低旁瓣。
- **估计500 Hz：** 幅度主峰仍位于0附近，降至约63662。当前相位约定下，对齐点Q约63662，I相对很小。由于采用左端点离散采样，零误差处I约为1，而不是数学连续积分的严格0；相对于100000的尺度可以忽略。非零误差处I与Q均可能有旁瓣。

### 实验二：三种DLL鉴别器

三行依次是相干超前减滞后、非相干超前减滞后包络、超前功率减滞后功率。中心S形区域集中在零误差附近，在完整扫描图中表现为较窄的正负峰。

- **初相0°：** 在0附近由负到正穿过零点，负误差给负输出，正误差给正输出；极值大致位于±0.5 Tc。前两种曲线中心区形状接近，功率差的外侧曲线形状不同。完整扫描中仍有PRN码旁瓣。
- **初相180°：** 相干鉴别器曲线上下翻转，中心斜率变负；包络差和功率差与0°情况保持一致。两张图采用相同纵轴尺度。
- 矩形码片的有限采样可能导致零误差处有很小残差，不应将其误解为真实传播延迟改变。鉴别器有效线性区主要在零点附近，远处旁瓣和其他零点不代表可靠锁定位置。

### 实验三：噪声影响

蓝实线为含噪声结果，黑虚线为同采样率无噪声基准，三行仍对应三种鉴别器。

- **0 dB：** 蓝线通常接近基准，中心过零形状清晰。
- **−10 dB：** 波动增加，中心趋势通常仍较清楚。
- **−20 dB：** 波动更明显，过零点和局部斜率受到扰动，但相关积分仍能保留一定的中心趋势。
- **−50 dB：** 输出通常被噪声严重扰乱，中心S形难以稳定辨认，可能出现伪过零点。各图纵轴自动适应含噪声幅度，不能只看屏幕上曲线高度判断噪声大小。

这是固定种子的一次噪声实现，不是多次平均曲线，也不是闭环跟踪误差统计；不保证单次曲线每个位置的偏差都随SNR下降而单调增加。可结合黑虚线观察，不把一次过零偏移当作统计精度。

## 简要原理解释

### 1. 自相关为什么形成尖峰

收发采用同一PRN20码。两个码对齐时，±1码片相乘均为+1，积分得到最大值；错开后正负项相互抵消。矩形码片随偏移发生线性重叠，形成近似三角主峰。

30 ms仍显式进入信号模型，但C/A码周期为1 ms，30 ms正好是30个码周期，仅靠这种周期码相关无法区分整数毫秒延迟。横轴为估计误差，不能用峰位0推断实际传播时延为0。

### 2. 多普勒误差为什么降低峰值

去载波后剩余频偏 `df=fd-fdHat`。对齐点的连续时间归一化相关为：

`Z/N ≈ exp(j*phi0)*exp(j*pi*df*Tp)*sinc(df*Tp)`，这里 `sinc(x)=sin(pi*x)/(pi*x)`。

频率正确时幅度为1。500 Hz残余频偏在1 ms中转过半圈，相量部分抵消，幅度为 `2/pi≈0.63662`，约损失3.92 dB。当前初相下平均相量主要指向Q轴。代码直接生成信号并积分，没有用理想三角曲线替代实际PRN输出。

### 3. 三种鉴别器及相位影响

令 `ZE`、`ZL` 分别为超前、滞后复相关输出，采用课件第20页的实验公式：

- 相干差：`Dc = real(ZE)-real(ZL)`。
- 非相干包络差：`De = abs(ZE)-abs(ZL)`。
- 功率差：`Dp = abs(ZE)^2-abs(ZL)^2`。

超前本地码为 `c(t-tauHat+d/2)`，对应误差 `epsilon-0.5`；滞后本地码为 `c(t-tauHat-d/2)`，对应 `epsilon+0.5`。因此正的小延迟误差使超前支路更接近对齐，E>L，得到正输出。DLL利用此符号与大小修正码相位。本实验扫描的是鉴别器的静态输出，并未加入环路滤波器和码NCO构成动态闭环。

初相变为180°时，两支路复相关一起乘−1，实部差反号，而绝对值、模平方不变。非相干方法因此能避免这种180°相位模糊导致的方向反转。

注意：课件第12页还介绍了 `(E-L)/(E+L)` 形式的归一化包络鉴别器，但第20页实验示例明确使用不带分母的 `E-L`；本程序按实验示例实现，未混用两种公式。

### 4. 噪声为什么扰动过零点

噪声叠加到E、L相关结果，使二者的差随机波动；由此造成过零点偏移、斜率变化和判别错误。包络及功率运算还会带来非线性噪声项。信号越弱，随机项相对有用差值越大，DLL越难保持可靠同步。

### 5. 课件思考题：为什么极低信噪比也能工作

本地码解扩与积分可以把匹配信号相干累加，而零均值噪声主要随机累加。在独立离散噪声模型中，信号和幅度随N增长，噪声和标准差约随sqrt(N)增长，相关后的功率信噪比可获得约N倍改善。本实验噪声节N=20000，对应约43 dB的理想离散积分增益，所以输入−20 dB时仍可能看出相关结构；−50 dB已难以仅靠这1 ms积分稳定辨认。

真实接收机还依赖码/载波同步、更长积分、滤波以及必要的非相干积累。这里的43 dB建立在示例的独立采样噪声定义上；不能通过增加实际接收机采样率就凭空获得同样的增益，也不能将输入SNR直接等同于C/N0。实际噪声带宽、采样相关性、数据翻转、频率误差和信号动态都会限制积分收益。
