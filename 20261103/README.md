## 操作步骤

### 1. 打开文件与运行顺序

1. 将MATLAB当前文件夹切换到本文件夹`20261103`，双击所需`.slx`文件。
2. 按“一阶 → 二阶 → 三阶 → 噪声模型”的顺序展示。每个模型包含多套并行电路，点击一次“运行”即可计算该模型内全部电路。

## 简要原理解释

### 1. 闭环为什么能够跟踪

负反馈将输入与当前输出相减，产生误差。误差经各增益和积分支路形成输出变化，再反馈修正后续误差。阶跃表示目标突然改变；斜坡表示目标以恒定速度变化；抛物线表示目标以恒定加速度变化。

一阶、二阶、三阶模型分别具有1、2、3个闭环积分环节。稳定且参数匹配时，一阶能对阶跃实现零稳态误差；二阶还可对斜坡实现零稳态误差；三阶还可对匀加速输入实现零稳态误差。

一阶单位斜坡误差为1/w0，本模型w0=4，故为0.25。二阶单位加速度误差为1/w0²，本模型w0²=3.559986，故约0.2809。更高阶输入对较低阶环形成持续跟踪负担，因此一阶的匀加速误差持续增长。

### 2. 为什么会超调和振荡

多条积分支路具有记忆和动态响应，误差改变方向后，内部状态不会立即消失，因此二阶、三阶可能超过目标值，再逐渐回落。只要振荡衰减并最终稳定，这种超调本身并不代表不稳定。

### 3. 带宽为什么影响速度和噪声

带宽通过增益体现。保持课件典型系数不变时，提高Bn会提高w0，使环路更快响应目标变化；缩小带宽则使响应变慢，同时减少传到输出的噪声。需要在动态跟踪速度与随机误差之间取舍。

对双边白噪声功率谱密度Sn=1、直流增益为1的理想连续闭环，稳态输出噪声功率约为2BnSn。因此1 Hz与0.1 Hz的理论功率约为2和0.2，RMSE约为1.414和0.447。相同等效噪声带宽下，一阶和二阶的理想稳态白噪声功率接近，不能简单认为阶数越高就一定越能抑噪。

噪声块的Noise power是谱密度参数，不是输出样本的均方值；本设置的输入噪声均方值约为1/0.01=100。只检查输入均方值约100不能独立证明设置正确，例如0.1/0.001也等于100，但环路看到的低频谱密度不同。

### 4. 为什么统计干净输入减输出并去掉暂态

本实验关心的是输出估计相对于真实输入的误差，因此统计TraErr=r-y。如果改用带噪输入减输出，就把输入噪声直接混入评价，不能正确体现输出的平滑效果。

噪声功率为mean(Noise.^2)，跟踪误差均方值为mean(TraErr.^2)，RMSE为后者的平方根。误差含偏置时，均方值还包含偏置平方，不等于去均值后的方差。

开始阶段积分器从0建立输出，包含确定性的启动误差；默认排除前50秒用于分析稳态。去掉暂态不保证均方值一定下降，因为不同时间段还存在随机波动。窄带输出相邻样本相关性强，记录45001点不等于45001次独立观测；有限记录偏离理论值是可能的，可延长仿真或多次更换Seed重复统计。

## 常见问题

- **找不到out：**先运行噪声模型，确认Single simulation output开启，然后在MATLAB命令窗口输入`out`或`whos out`。
- **out中没有对应Noise/TraErr字段：**可能运行了其他模型覆盖out，或修改了To Workspace变量名；重新运行噪声模型并核对8个字段。
- **tout与信号长度不一致：**变步长求解器时间与0.01秒固定记录时间不同是正常现象；不要用tout直接给这些Array数据配时间。
- **稳态结果为NaN：**记录没有覆盖50秒之后的有效区间，需要延长仿真；不要把NaN填写成0。
- **第一部分曲线与截图数值不同：**先比较形状、误差收敛规律，再核对带宽、斜率和停止时间；课件截图不是统一参数下的数值标准。
- **result.txt内容没变：**模型运行只更新out，必须随后运行read_out才会更新文本文件。
